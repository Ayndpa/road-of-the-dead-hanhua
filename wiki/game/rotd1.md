# Road of the Dead（死亡之路）

> 2011 年发布于 Flash 平台。扮演当地修理工**约翰·克里斯曼（John Creasman）**，
> 在僵尸末日中沿 **65 号公路**疾驰，逃出被隔离的**埃文斯城**。

## 核心玩法

你要在高速公路上尽量开得更远。撞上敌人、甩掉扒车者、击落直升机都能得分，
攒下的**公路点数（RP）**可以在车库购买升级。

| 机制 | 说明 |
|---|---|
| 加速 / 刹车 / 转向 | 基础驾驶操作，可在选项中自定义按键 |
| 手刹 | 漂移甩尾，更精准地避开障碍 |
| 雨刷 | 掸掉糊满挡风玻璃的血 |
| 喇叭 | 提醒平民让路；也更容易撞出「飞溅撞击」 |
| 手枪 | 打下扒在引擎盖上的敌人（几发就会打碎挡风玻璃） |
| 感知 | 切换为固定俯视图，显示自己与前方危险/敌人 |
| 水桶 | 撞击蓝色大水桶可扑灭起火的引擎，并冲掉挡风玻璃上的血 |

### 得分：连击与飞溅

- **飞溅撞击**：高速用车头正中撞上目标（活的死的都算）触发，提供额外倍率；
  用喇叭更容易对丧尸打出。撞平民**没有**奖励。
- **连击**：短时间连续命中多个敌人，连击越长得分越高；**撞到平民会中断连击**。

### 引擎盖上的敌人

车速不够快时，被撞的丧尸和士兵会**扒住引擎盖**。甩掉他们的方式：

- 用手刹**狠狠撞侧墙**，或撞上废弃车辆；
- 用**手枪**射击。

没有挡风玻璃时尤其危险 —— 没有东西阻挡，丧尸会钻进车里，直接致命。

### 特殊威胁

- **突变僵尸**：极其强壮抗打，无论怎么撞都会死死扒住引擎盖，最好避开。
- **直升机**：把军队惹毛后会派直升机追杀，需让它撞上几次高速公路的大路牌才能击落。

## 游戏模式

| 模式 | 英文 | 说明 |
|---|---|---|
| 亡命大逃亡 | The Great Escape | 主线，普通难度，逃出被隔离的城市 |
| 地狱公路 | Highway To Hell | 困难难度，通关《亡命大逃亡》解锁 |
| 死亡计时 | Dead On Time | 限时模式，击杀丧尸赚取额外时间 |
| 警察国度 | Police State | 一人军团对抗军方残酷阻击 |

详见[游戏模式](/game/modes)。

## 车库升级

在车库消费 RP 强化车辆，共 8 类、每类 3 级：

| 升级 | 英文 | 作用 |
|---|---|---|
| 防弹衣 | Body Armor | 提高抗撞击 / 抗伤害能力 |
| 感知 | Perception | 强化俯视感知视图 |
| 枪械 | Firearm | 强化随身手枪 |
| 挡风玻璃 | Windshield | 更耐冲击，减少被扒车风险 |
| 引擎 | Engine | 提升加速与耐久 |
| 保险杠 | Bumper | 提升正面撞击承受力 |
| 轮胎 | Tires | 提升操控与转向 |
| 喇叭 | Horn | 强化引怪 / 驱散平民效果 |
