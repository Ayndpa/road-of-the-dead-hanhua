# 敌人

## Road of the Dead 2

游戏中的敌人（与友方平民）种类繁多，生存指南会随着你遇到新事物逐步解锁。

| 名称 | 英文 | 说明 |
|---|---|---|
| 普通丧尸 | Common Undead | 最常见的尸群 |
| 丧尸士兵 | Undead Soldier | 变成丧尸的士兵 |
| 敌方士兵 | Enemy Soldiers | 会开枪射击你的活人士兵 |
| 钉刺兵 | Spike Soldiers | 带钉刺装备的士兵 |
| 突变体 | Mutants | 强壮、会跳跃扑向车辆 |
| 阿尔法突变体 | Alpha Mutants | 突变体中的强化个体，常带队出现 |
| 暴食者 | Feeders | 进食中的丧尸，不主动攻击（除非被射击） |
| 掠夺者 | Ravagers | 更具攻击性的变异体 |
| 鬼面兽 | Brutes | 重型变异体 |
| 蛴螬 | Grub | 会爬上车头保险杠的幼虫型丧尸 |
| 平民 | Civilians | 可接载并送往教堂/警察局换取 RP |
| 排爆小组 | Bomb Squad | 军方单位 |
| 攻击直升机 | Attack Choppers | 空中威胁 |
| 支援直升机 | Support Choppers | 可召唤的己方支援 |
| 轰炸机 | Bomber Jets | 会进行地毯式轰炸 |

### 行为要点

- **士兵丧尸**佩戴装甲头盔与护甲，会**随机挡下子弹**。
- **正在进食的丧尸**不会理会你，除非你向它开火。
- **突变体**有时 3–4 只结群，其中一只是**阿尔法突变体**，非常危险。
- 敌人会**跳跃扑咬**或**侧向抓附**车辆；高速能撞飞它们，低速则容易被扒上引擎盖。
- 侧向被扑咬时：**驾驶员猛按空格、机枪手猛按鼠标左键**可把它打下去；
  也可通过撞护栏/墙壁或高速磨蹭把侧面的突变体甩掉。
- 蛴螬爬上车头时，**驾车撞向障碍物**能把它撞成肉泥。

## Road of the Dead

| 类型 | 说明 |
|---|---|
| 僵尸 | 普通尸群，速度不够快时会扒上引擎盖 |
| 士兵 | 持有枪械，会远距离射击 |
| 突变僵尸 | 极强壮抗打，无法靠撞击甩掉，最好避开 |
| 直升机 | 高级威胁，需引它撞高速公路大路牌数次才能击落 |
| 平民 | 撞到会扣分并中断连击；按喇叭可让他们让路 |
