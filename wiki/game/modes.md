# 游戏模式

## Road of the Dead

| 模式 | 英文 | 难度 / 玩法 |
|---|---|---|
| 亡命大逃亡 | The Great Escape | 主线，**普通**难度：在僵尸末日中逃出被隔离的城市 |
| 地狱公路 | Highway To Hell | **困难**难度，通关《亡命大逃亡》后解锁 |
| 死亡计时 | Dead On Time | **限时**：击杀丧尸赚取额外时间，活得越久走越远 |
| 警察国度 | Police State | **军事**：一人军团硬抗军方的残酷阻击 |

排行榜分列《死亡计时》与《警察国度》的最远距离。

## Road of the Dead 2

### 剧情与战役

| 模式 | 英文 | 玩法 |
|---|---|---|
| 剧情模式 | Story Mode | 主线，扮演两名幸存者（司机 / 机枪手）求生逃离 |
| 硬核模式 | Hardcore | 全程**不死**通关剧情模式 |
| 亡命孤军 | Lost Guns | 军事行动失败后，作为逃兵成为军方敌人 |
| 用户战役 / 挑战 | Custom / Challenge | 玩家自制并分享的战役与挑战 |
| 战役编辑器 | Campaign Editor | 制作模板、区域、战役（见[Road of the Dead 2](/game/rotd2)） |

### 挑战模式

| 模式 | 英文 | 玩法 |
|---|---|---|
| 救援行动 | Rescue OP | 扮演救援直升机的机枪手，从被围困建筑中营救平民 |
| F.U.B.A.R. | F.U.B.A.R. | 与军方正面对抗 |
| 死亡之州 | Dead State | 生存模式，尽可能开得更远 |
| 变异体熔毁 | Mutant Meltdown | 直面变异体的疯狂挑战 |
| 时间耗尽 | Out of Time | 与时间赛跑，击杀丧尸换时间 |

> 通关剧情模式可解锁部分挑战模式；部分模式还有各自的解锁条件（如通关《亡命孤军》
> 解锁后续挑战）。

### 通关 / 结局

二代的剧情可以走向不同结局，游戏内记录的类型包括：
黑屏结局、红屏结局、白屏结局、直升机逃生结局、驾车离去结局、公路过渡结局、核爆结局。
