# Road of the Dead 2（死亡之路 2）

> 初代的续作。舞台仍是**埃文斯城**，但疫情进一步失控、军方节节败退。
> 你可以扮演两名分工合作的幸存者 —— 一人开车、一人持枪 —— 在更大的城区与公路上求生。

## 双角色协作

二代最大的变化是**两名可操作角色**：

- **黛安（Diane）** 与 **科切塔（Cocheta）**，各自拥有独立的**武器配置**与**个人属性等级**；
- 一人当**司机**、一人当**机枪手**，可用切换键随时交换座位；
- **特长（Perks）是两人共享的**；
- 遇到侧面扑咬的敌人时：驾驶员猛按空格（急转键）、机枪手猛按鼠标左键，可把变异体打下去。

建议让两人轮流开车与射击，才能均衡升级。

## 个人属性

属性会随着游玩自动成长（不必手动加点）：

| 属性 | 英文 | 作用 |
|---|---|---|
| 驾驶 | Driving | 配合轮胎决定转向能力 |
| 坚韧 | Toughness | 碰撞/爆炸时的操控、车身爆炸伤害、对抗侧向抓附 |
| 瞄准 | Aiming | 武器瞄准的响应速度 |
| 操控 | Handling | 装备/卸下武器速度、猛烈碰撞的颠簸与恢复 |
| 装弹 | Reloading | 装填该武器的速度 |
| 伤害 | Damage | 每发子弹造成的伤害 |
| 精准度 | Accuracy | 开火散布与霰弹枪后坐力，以及恢复速度 |
| 容量 | Capacity | 弹匣与可携带弹药总量 |

## 任务与补给

在城里停靠特定地点即可交互（停车时按喇叭还能接载平民）：

| 地点 | 作用 |
|---|---|
| 车库 Garage | **免费修车**，用 RP 购买车辆升级与特长 |
| 教堂 Church | 平民下车点；用 RP 购买特长与药品 |
| 警察局 Police Station | 平民下车点；购买特长、武器、武器升级与弹药 |
| 武器箱 Weapon Crate | 购买武器、武器升级、弹药与车载武器 |
| 弹药点 / 废弃军车 | 免费补给弹药 |

> 把平民送到教堂或警察局可获得额外 RP。车上有丧尸时平民不会上车，先清干净再按喇叭。

## 资源与药品

- **医疗包（Med Patch）**：治愈伤势，撑到下一次危及生命的时刻。
- **类固醇针剂（Steroid）**：短时间内免疫子弹、爆炸等身体伤害。
- **特长（Perks）**：弹药拾取、司机换位、升级、降低花费、任务速度、直升机支援等。
- **直升机支援**：短暂召唤直升机协助；剧情模式、救援行动、F.U.B.A.R. 中不可用。

## 威胁与应对

- **敌人种类**：普通丧尸、士兵丧尸、阿尔法突变体、暴食者、掠夺者、鬼面兽、蛴螬、突变体、钉刺兵、敌方士兵。
- **士兵丧尸**佩戴装甲头盔与护甲，会**随机挡下子弹**。
- **正在进食的丧尸**不会主动攻击，除非你向它开火。
- **突变体**常 3–4 只结群，其中一只是**阿尔法突变体**；会向车**跳跃扑咬**，落点要提前甩开。
- **陷阱**：感应地雷、钉刺带、漏油、安全围栏、消防栓、油罐车等。
  - 地雷/车辆/油罐车爆炸能成片清怪，也可能引发连锁爆炸；
  - 打爆**消防栓**喷出的水柱可扑灭起火的引擎，水也能给冒烟的引擎降温；
  - 滑过**漏油**后不要撞到任何东西。
- **高速优势**：速度越快，越容易把敌人撞飞/撞碎，而不是让它们扒上引擎盖。

## 战役编辑器

二代内置**战役编辑器**，其构建模块自上而下是：

1. **模板（Pattern）**：一段 90 米 / 5 个路段的短路，可含障碍、建筑、路面、丧尸、士兵、树木等；
2. **区域（Area）**：一组绑定的模板；
3. **组（Group）**：包含若干区域，可随机或顺序生成，并用「可链接组」串联；
4. **战役（Campaign）**：**故事**战役（线性、必须有结局）或**挑战**战役（无限、有目标与目标值，如击杀 500 只丧尸）。

模板、区域、战役都可**私有或公开**保存并分享给其他玩家使用。
