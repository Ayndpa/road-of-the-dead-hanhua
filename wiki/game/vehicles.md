# 车辆与升级

## Road of the Dead 2

玩家的座驾是一辆可不断强化的**悍马（Hummer）**。在**车库**可以**免费修理**车辆，
并用 RP 购买升级；「车载武器」则在武器箱等处安装。

### 维修与升级

| 项目 | 英文 | 作用 |
|---|---|---|
| 维修轮胎 | Repair Tires | 恢复轮胎状态 |
| 维修引擎 | Repair Engine | 防止引擎着火爆炸 |
| 维修保险杠 | Repair Bumper | 恢复正面撞击防护 |
| 维修装甲 | Repair Armor | 维持对猛烈碰撞的防护 |
| 升级轮胎 | Upgrade Tires | 结合驾驶技能，提升转向、刹车与应对钉刺带/漏油 |
| 升级引擎 | Upgrade Engine | 提升加速与引擎耐久 |
| 升级保险杠 | Upgrade Bumper | 提升正面抗撞能力 |

### 安装武器

| 武器 | 说明 |
|---|---|
| 车载机枪（Mounted MG） | 高火力，有**过热**机制，无法装填 |
| 车载火箭发射器（Mounted Rocket Launcher） | 破坏力最强，无法装填 |

### 车辆耐久因素（编辑器 / 挑战参数）

游戏内存在 **Player Car HP Factor、Vehicle HP Factor、Player Body HP Factor** 等
难度参数，可见车辆与角色都有独立的生命值设定。

### 路上会遇到的车

- **废弃车辆 / 行驶中的汽车 / 大型车辆**：撞击对象，也会爆炸伤及周围；
- **废弃军用悍马 / 军用卡车**：停下可**免费收集弹药**；
- **油罐车**：爆炸威力大，可用来清怪，也容易连锁；
- **攻击 / 支援直升机、轰炸机**：空中单位。

## Road of the Dead

初代在车库用 RP 强化车辆，共 **8 类、每类 3 级**：

| 升级 | 英文 |
|---|---|
| 防弹衣 | Body Armor |
| 感知 | Perception |
| 枪械 | Firearm |
| 挡风玻璃 | Windshield |
| 引擎 | Engine |
| 保险杠 | Bumper |
| 轮胎 | Tires |
| 喇叭 | Horn |

购买全部升级可解锁成就「坦克（Tank）」。
撞**蓝色大水桶**可灭火、清血；撞**废弃车辆**或**侧墙**可甩掉引擎盖上的敌人。
