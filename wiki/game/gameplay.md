# 玩法与操作

《Road of the Dead》的核心是一句话：**别停车，别被扒车，开得越远越好。**
下面把两代共通的驾驶、战斗与生存机制整理在一起。

## 视角

- 默认是**追尾视角**，看得到车头与前方路面；
- 初代有**感知（Perception）**模式：切换为固定俯视图，用图标显示自己、前方危险与敌人。

## 驾驶

| 操作 | 初代 | 二代 |
|---|---|---|
| 加速 / 刹车 | 有（可自定义） | 有（默认加速键 / 刹车键） |
| 左右转向 | 方向键 | 方向键 |
| 急转 / 甩尾 | **手刹** | **急转键（默认空格）** |
| 雨刷 | 有 | 引擎着火时用**水**降温/灭火 |
| 喇叭 | 有（引怪 / 驱散平民） | 默认 `F` |

- **速度决定命运**：速度越快，越容易把敌人撞飞或撞碎，而不是让它们扒上引擎盖。
- 有时也要**主动减速**：在合适区域慢行，才能安全通过陷阱与拥堵。
- 急转（二代空格 / 初代手刹）撞侧墙几次，可以把引擎盖上的敌人甩下去。

## 战斗

- **撞击**：用车头撞敌人得分；高速正中命中触发**飞溅撞击**，提供额外倍率。
- **连击**：短时间连续命中多个敌人可叠加连击，**撞到平民会中断连击**。
- **枪械**：二代用鼠标瞄准、左键开火，数字键/滚轮切武器，装弹键换弹；
  初代随身只有一把手枪，主要用于打下引擎盖上的敌人。
- **车载武器**：二代可安装车载机枪（有过热机制）与车载火箭发射器，**无法装填**，需重新购买补弹。

## 引擎与车辆状态

- 车辆有**轮胎、引擎、装甲、保险杠**等状态；受损后**去车库免费修理**。
- 引擎会**冒烟→着火**，着火后若不及时处理会**爆炸**：
  - 撞击蓝色**水桶 / 消防栓水柱**可灭火，也能冲掉挡风玻璃上的血；
  - 水还能给冒烟的引擎**降温**。

## 平民与 RP

- **公路点数（RP）** 是通用货币，用于购买升级、武器、特长与药品。
- 停车时按**喇叭**可接载平民，把他们送到**教堂或警察局**可获得 RP 奖励。
- 车上有丧尸时平民不会上车；撞死平民会**扣分并中断连击**。

## 常见陷阱（二代）

| 陷阱 | 应对 |
|---|---|
| 感应地雷 | 远处射爆，注意连锁反应 |
| 钉刺带 | 会扎爆轮胎，升级轮胎可更好应对 |
| 漏油 | 滑过后一段时间不要撞到任何东西 |
| 安全围栏 | 撞上会减速/受损 |
| 消防栓 | 打爆后水柱可灭火 |
| 油罐车 / 完好车辆 | 持续射击会爆炸，可用来清怪 |

## 存档

两代都会自动保存进度（初代存于 Flash 本地存储，二代同样）。**清除浏览器缓存可能
导致存档丢失**，注意不要关闭本地存储。
