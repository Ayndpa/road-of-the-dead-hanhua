# 成果一览

本页按“玩家能感知到的东西”列出汉化内容，便于评估与验收。

## 一代

### 字幕

- **对白字幕**：246 条，内嵌在 `DTSound.Play()` 播放路径上，所有语音/音效都经过它查表。
- **开场流式音轨**：紧急广播 + 电台混音共 26 段，按主时间轴帧号换算音轨时间同步。
- **长台词分段**：优先用 ASR 的真实语音分段做时间对齐，中文按各段英文长度分配并拉伸到实际时长。
- **中英逐句对齐**：中英各自按句子拆分，取两者中更细的一方，另一方在多余分段里保持同一句。
- **多行堆叠**：不同来源各占一行，同一来源重开一句只替换自己那行。

### 字幕交互

- `F2`：字幕总开关，带屏幕提示。
- `F3`：字幕设置面板。
  - 显示模式：仅英文 / 仅中文 / 中英双语（默认仅中文）。
  - 字号：小 / 中 / 大（默认中）。
  - 背景：显示 / 隐藏（默认显示）。
  - 面板底部用真实字幕渲染路径显示示例，改动立即生效。
  - 设置写入 `SharedObject rotd_zh_subtitles`，下次启动自动恢复。

### 文本与字体

- UI 烘焙文本：224 个中的 174 个汉化。
- 运行时文本：成就 / 提示框 / 关卡介绍 / 地点 / 结算，共 233 处。
- 标题 logo、制作名单、HUD 数字、品牌字样保持原样。
- 主菜单 7 个手绘透视按钮用中文矢量重绘。

## 二代

- 语音字幕 **849 条**，开场流式音轨 **43 段**。
- 运行时 AS3 字面量（成就 / 帮助 / 关卡 / 武器名等）汉化。
- 烘焙 UI 文本 + 运行时文本框按 12 个字形槽分别适配。
- 修正多处运行时问题：
  - 开场跳过仍重播（`DoStartGame` 二次触发）。
  - 选项 / 成就页因字体 layout 缺失而空白。
  - 运行时 `face="Arial"` 命中原版拉丁字体导致中文空白。
  - 游戏内选项栏动态文本基线偏移。

## 体积

构建的中间步骤都用未压缩 SWF（FWS）读写，最后重新 zlib 压缩成 CWS。

| 阶段 | 一代 | 二代 |
|---|---|---|
| 未压缩中间产物 | ~30.19 MB | ~57.6 MB |
| zlib 压缩后 | 27.43 MB | 49.1 MB |

二代多字体本身仍会比英文原版多几 MB 字形数据。
