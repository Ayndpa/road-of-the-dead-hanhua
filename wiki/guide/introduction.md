# 汉化项目介绍

给 Flash 游戏 **Road of the Dead**（Evil-Dog / SickDeathFiend, 2011）与其续作
**Road of the Dead 2** 加中文字幕和中文 UI 的完整工具链。

所有改动都是**对原始 SWF 做无损结构修改**：没有动源码逻辑（除少量字符串），
没有替换美术资源，随时可以从原版重新构建。

::: tip 设计原则
1. **可重建** —— 只改结构，不改数据源；翻译来自平台 CSV，字体来自开源字库。
2. **逐字形适配** —— 原版每个视觉字形单独配一套中文字形，而不是一刀切。
3. **字节级克制** —— 标题 logo、制作名单、成就数字等保持原样。
:::

## 成果

### 一代

| 内容 | 状态 |
|---|---|
| 中文字幕（246 条对白） | 已内嵌 |
| 开场流式音轨字幕（紧急广播 + 电台混音，26 段） | 按主时间轴帧同步 |
| 多行堆叠字幕（电台与主角同时说话各占一行） | 完成 |
| F2 字幕开关（带屏幕提示） | 完成 |
| F3 字幕设置面板（仅英文 / 仅中文 / 中英双语、字号、背景，自动保存） | 完成 |
| UI 文本汉化（224 个烘焙文本中的 174 个） | 完成 |
| 运行时文本汉化（成就 / 提示框 / 关卡介绍 / 地点 / 结算，233 处） | 完成 |
| 标题 logo、制作名单、数字保持原始字体设计 | 逐字节未改动 |
| 主菜单按钮（矢量图形文字） | 用 Dirty Ego 风格中文矢量重绘 |

### 二代

- 12 种原版真实字形各配一套中文字形（展示体 / 无衬线 / 衬线 / 黑体 / 斜体）。
- 运行时 AS3 字面量、烘焙 UI 文本、语音字幕（849 条）与开场流式音轨（43 段）。
- 主菜单、生存手册书脊、游戏内选项栏等矢量与静态标签对齐。
- 修复了开场跳过仍重播、选项页空白、运行时中文字体命中错误等运行时问题。
