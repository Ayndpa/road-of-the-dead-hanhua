#### **载具/驾驶员升级**

| 升级名称 | 花费 | 效果 | 备注 |
| --- | --- | --- | --- |
| 轮胎 |  | 提升载具的操控性以及对[钉刺带](./spike-strips "Spike Strips")、[尸体](./corpses "Corpses")和[漏油](./oil-spills "Oil Spills")的耐受性。 | |
| 引擎 |  | 提升加速、最高速度和耐久度。 | 在引擎被摧毁前，装甲会代为承受伤害。若引擎被摧毁，载具也会被摧毁。 |
| 装甲 |  | 提升耐久度。 |
| [车载武器](./mounted-weapons "Mounted Weapons") |  | 将该武器加装到载具上以供使用。 | 任意时刻只能有一种武器处于激活状态。弹药无法补给，耗尽后必须重新购买。 |
| 驾驶 | 仅通过躲避障碍物即可升级。 | 提升载具操控性。不共享于两名角色之间。 | |
| 坚韧 | 仅通过吸收外部伤害即可升级。 | 提升载具乘员在 F.U.B.A.R. 中对外部爆炸和枪击的耐受性。共享于两名角色之间。 | |

#### 武器与升级

| 武器名称 | 专属角色 | 行为 | 备注 |
| --- | --- | --- | --- |
| 手枪 | [黛安](./diane-roseworth "Diane Roseworth")/[科切塔](./cocheta-solomon "Cocheta Solomon") | 拥有无限备用弹药、综合属性平平的半自动武器。 | 武器不共享于两名角色之间。 |
| 霰弹枪 | 黛安 | 弹容量尚可的半自动武器，近距离伤害高但装弹缓慢。 |  |
| 紧凑冲锋枪 | 全自动武器，射速、精准度、伤害和装弹速度都非常高。 | 需要预先花费 RP 购买 |
| 突击步枪 |
| 突击冲锋枪 | 科切塔 | 高射速、高精准度的全自动武器。弹药和弹匣容量平平。装弹快。 |  |
| 自动霰弹枪 | 全自动武器，弹容量和备用弹药量中等偏大，近距离伤害高。装弹慢。 | 需要预先花费 RP 购买 |
| 轻机枪 | 全自动武器，伤害、备用弹药、容量和射速都不错。装弹慢，精准度平平。 |

### 武器属性

##### 所有武器属性均按武器对其使用者专属。

| 升级名称 | 花费 | 效果 |
| --- | --- | --- |
| 伤害 |  | 提升武器的伤害。 |
| 精准度 |  | 降低武器的后坐力和偏移。 |
| 容量 |  | 提升武器内和备用弹药的最大携带量。 |
| 瞄准 | 通过命中目标升级 | 降低武器的后坐力和偏移。 |
| 操控 | 随着武器在战斗中使用的过程升级 | 提升武器切换速度和后坐力恢复。 |
| 装弹 | 通过装弹升级 | 提升装弹速度。 |
