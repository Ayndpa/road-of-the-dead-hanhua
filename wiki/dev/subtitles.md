# 语音字幕

## 钩子位置

游戏**所有音效 / 语音都只经过 `DTSound.Play()`**（621 个 `StartSound` 只是放在
`MC_MCWithAllSounds` 里预载，不参与播放）。因此钩子放在 `DTSound.Play()`：

```javascript
m_SoundChannel = m_Sound.play(...);
SubtitleOnPlay(this);          // 用 getQualifiedClassName(m_SoundClass) 查表
```

- 字幕表以 `\uXXXX` 纯 ASCII 形式编译进 ABC，避免编译器编码问题。
- 初始化挂在 `BasicGame.Init()`，否则开场（无对白音效）阶段系统不会启动。

## 时间对齐

长台词按句子拆分、分段显示：

- 优先用 `data/asr_all.json` 的**真实语音分段**（每段 start / end）做时间对齐 ——
  中文按各段英文长度分配、拉伸到该段的实际时长，因此字幕只会说一句显一句，
  不会在静音里提前或空转；
- 没有 ASR 分段时才退回按整段时间比例均分。

## 句子拆分

中英**各自按句子拆分**，分段数量取两者中切得更细的一方：

- 英文按 `.` / `!` / `?` 断句，中文按 `。！？` 断句；
- 另一方在多余的分段里保持同一句不跳动；
- 英文断句会跳过小数点（`64.7`）与常见缩写（`U.S.`、`Mr.` 等），否则这些点会被当成句末、
  凭空多出几句英文，把中文整体挤后一句而与语音脱节（中文看起来「更慢」）。

## 多行堆叠

不同来源各占一行，同一来源重开一句只替换自己那行 —— 例如电台与主角同时说话时各占一行。

## 双语

每条字幕同时带英文原文与中文翻译（取自平台 CSV 的 `original` / `translation` 两列），
运行时按设置显示其中一种或上下两行全显示；长台词分段的每个小段也各自成对，
保证中英逐句对齐。

## 字幕设置面板（F3）

显示方式全部在运行时的 `DTSound` 覆盖层里绘制，不依赖原始 SWF 的菜单资源：

- 按 `F3`（关闭时再次按 `F3` / `Esc`）开关面板；
- 鼠标点击该行即切换取值，键盘用 `↑↓` 选择行、`←→`（或回车）修改；
- **显示模式**：仅英文 / 仅中文 / 中英双语（默认仅中文，双语时英文在上、中文在下）；
- **字号**：小 / 中 / 大（默认中）；
- **背景**：显示 / 隐藏（默认显示，隐藏后仅保留描边发光）；
- 面板底部用**真正的字幕渲染路径**显示一条示例字幕，随改动立即变化；
- 背景框宽度按当前字幕实际渲染宽度自适应（居中、左右留白）。

设置写入 `SharedObject rotd_zh_subtitles`，下次启动自动恢复；`F2` 仍是总开关。
